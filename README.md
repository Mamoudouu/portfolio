# Portfolio de Mamoudou Camara

Site d'une page, sans dépendance externe : HTML, CSS, et un nuage de particules en WebGL (Three.js, copie locale dans `vendor/`).

- `index.html` : le contenu
- `style.css` : la mise en forme
- `main.js` : le moteur de particules (shaders)
- `interface.js` : les animations d'interface
- `polices/` : la police Archivo (licence SIL Open Font)
- `serveur.js` : petit serveur d'aperçu local (`node serveur.js`, puis http://localhost:3300)

Publié avec GitHub Pages depuis la branche `main`.
